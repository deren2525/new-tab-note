# ADR-001 同期競合では本文を自動破棄しない

- 状態: 採用
- 対象要件: `SYNC-003`, `SYNC-004`

## 背景

同じノートを複数端末で編集すると、ローカルとリモートの両方が最後の同期状態から変更されることがある。
単純なlast-write-winsは実装しやすいが、ユーザーが入力した本文を通知なしに失う可能性がある。

## 決定

最後に同期した本文を共通の基準として、ローカルとリモートの変更を判定する。
片方だけが変化した場合はその変更を採用する。
両方が変化した場合は競合として扱い、ユーザーが選択するまでどちらの本文も破棄しない。

初期実装では、競合時にローカル本文を維持し、リモート本文を別の値として保持して選択を求める。
将来、差分表示や自動マージを追加しても、この「通知なしに破棄しない」という要件は維持する。

## 影響

- ノートモデルまたは同期状態に競合を表現する情報が必要になる。
- `App.vue` 内の同期マージ処理を純粋関数へ分離し、3-way比較を単体テストする。
- 競合解決UIは変更可能だが、選択前に本文を上書きしてはならない。
- 旧データなど基準本文が不明な場合は、安全側として競合扱いを選べるようにする。
